Resources

  • Addon Deployment

    Resource for attaching cluster profiles as addon deployments to an existing cluster.

  • Alert

    Resource for managing project-level alert channels in Spectro Cloud.

  • Appliance

    A resource for creating and managing appliances for Edge Native cluster provisioning.

  • Application

    Resource for managing applications deployed through Spectro Cloud.

  • Application Profile

    Provisions an Application Profile. App Profiles are templates created with preconfigured services. You can create as many profiles as required, with multiple tiers serving different functionalities per use case.

  • Audit Trail

    Resource for managing tenant audit trail data sinks (CloudWatch or Splunk) in Spectro Cloud.

    Resource for managing backup storage locations in Spectro Cloud.

    Resource for managing MaaS cloud accounts in Spectro Cloud.

    Resource for managing AKS clusters in Spectro Cloud through Palette.

    Resource for managing Apache CloudStack clusters in Spectro Cloud through Palette.

    Resource for managing AWS clusters in Spectro Cloud through Palette.

  • Cluster Azure

    Resource for managing Azure clusters in Spectro Cloud through Palette.

  • Cluster Brownfield

    Register an existing Kubernetes cluster (brownfield) with Palette. This resource allows you to import and manage existing Kubernetes clusters. Supported cloud platforms: (AWS (Iaas), Azure (Iaas), GCP (Iaas), Generic (Generic should be used for everything else that is not listed here), Apache CloudStack). This feature is currently in preview.

  • Cluster Config Template
