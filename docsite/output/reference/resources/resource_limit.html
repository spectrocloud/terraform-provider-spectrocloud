Resource Limit

Resource for managing tenant-wide Palette object quota limits in Spectro Cloud.

You can learn more about managing resource limit in Palette by reviewing the Default Resource Limit guide.

~> The resource_limit resource enforces a resource limit in Palette. By default, a resource limit is configured in Palette with default values. Users can update the resource limit settings as per their requirements. When a spectrocloud_resource_limit resource is destroyed, the resource limits will revert to the Palette default settings.

Example Usage

An example of managing an password policy in Palette.

resource "spectrocloud_resource_limit" "resource_limit" {
  alert                  = 101
  api_keys               = 201
  appliance              = 6001
  appliance_token        = 201
  application_deployment = 200
  application_profile    = 200
  certificate            = 20
  cloud_account          = 355
  cluster                = 300
  cluster_group          = 50
  cluster_profile        = 2500
  filter                 = 200
  location               = 100
  macro                  = 6000
  private_gateway        = 100
  project                = 200
  registry               = 200
  role                   = 100
  ssh_key                = 300
  team                   = 100
  user                   = 300
  workspace              = 60
}

import existing resource limit## Import

In Terraform v1.5.0 and later, use an import block to import the resource spectrocloud_resource_limit by using its id with the Palette context separated by a colon. For example:

import {
  to = spectrocloud_resource_limit.resource_limit
  id = "{tenantUID}" // tenant-uid
}

Using terraform import, import the resource limit using the tenant_uid or tenant_name colon separated with context. For example:

terraform import spectrocloud_resource_limit.example tenant_uid/tenant_name
