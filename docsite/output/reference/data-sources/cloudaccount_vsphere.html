Cloudaccount VSPHERE

Data source for looking up a vSphere cloud account by ID or name.

Example Usage

data "spectrocloud_cloudaccount_vsphere" "example" {
  name    = "vsphere-account"
  context = "project"
}

<!-- schema generated by tfplugindocs -->

Schema

Optional

  • context (String) The context of the cluster. Allowed values are project or tenant or ``.
  • id (String) The unique ID of the vSphere cloud account. Either id or name must be provided, but not both.
  • name (String) The name of the vSphere cloud account. Either id or name must be provided, but not both.

Read-Only

  • private_cloud_gateway_id (String) The ID of the Private Cloud Gateway associated with this vSphere cloud account.
