Data Sources

  • Appliance

    Provides details about a single appliance used for Edge Native cluster provisioning.

  • Appliances

    Provides details about a set of appliances used for Edge Native cluster provisioning. Various attributes could be used to search for appliances like tags, status, health, and architecture.

  • Application Profile

    Use this data source to get the details of an existing application profile.

  • Backup Storage Location

    Data source for looking up a backup storage location by ID or name.

  • Cloudaccount Apache Cloudstack

    Data source for looking up an Apache CloudStack cloud account by ID or name.

  • Cloudaccount AWS

    A data source for retrieving information about an AWS cloud account registered in Palette.

  • Cloudaccount Azure

    A data source for retrieving information about an Azure cloud account registered in Palette.

  • Cloudaccount Custom

    Data source for looking up a custom cloud account by ID or name.

  • Cloudaccount GCP

    A data source for retrieving information about a GCP cloud account registered in Palette.

  • Cloudaccount MAAS

    Data source for looking up a MaaS cloud account by ID or name.

  • Cloudaccount VSPHERE

    Data source for looking up a vSphere cloud account by ID or name.

  • Cluster

    Data source for looking up a cluster by name and retrieving connection details.

  • Cluster Config Policy

    Data source for retrieving information about a cluster config policy (maintenance policy).

  • Cluster Config Template

    Data source for retrieving information about a cluster config template. Tech Preview: This data source is in tech preview and may undergo changes.

  • Cluster Group

    Data source for looking up a cluster group by name within a given context.

  • Cluster Profile

    Data source for looking up a cluster profile by ID or name.

  • Filter

    Data source for looking up filter definitions by name.

  • IPPOOL

    Data source for looking up a private cloud gateway IP pool by name.

  • Macros

    Use this data source to get the ID of a macros resource for use with terraform import.

  • Pack

    This data resource provides the ability to search for a pack in the Palette registries. It supports more advanced search criteria than the pack_simple data source.

  • Pack Simple

    This data resource provides a simpler user experience for searching for a pack in Palette registries.

  • Permission

    Data source for looking up permissions by name and scope.

  • Private Cloud Gateway

    A data resource to get the ID or name of Private Cloud Gateway.

  • Privatecloudgateway DNS Map

    Data source for looking up private cloud gateway DNS mappings.

  • Project

    Data source for looking up a Spectro Cloud project by name.

  • Registration Token

    Data source for looking up a registration token by name or UID.

  • Registry

    Data source for looking up an OCI, Helm, or Spectro registry by name.

  • Registry Helm

    Data source for looking up a Helm registry by name.

  • Registry Oci

    Data source for looking up an OCI registry by name.

  • Registry Pack

    Data source for looking up a Spectro pack registry by name.

  • Role

    Data source for looking up a Spectro Cloud role by ID or name.

  • SSH Key

    The SSH key data source allows you to retrieve information about SSH keys in Palette.

  • Team

    Data source for looking up a team by ID or name.

  • User

    Data source for looking up a user by ID or email address.

  • Workspace

    Data source for looking up a Spectro Cloud workspace by name.
