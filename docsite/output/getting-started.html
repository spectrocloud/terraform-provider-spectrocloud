Getting Started

Pre-requisites

  • A Spectro Cloud account (sign up for a free trial)
  • Terraform 0.13+
  • kubectl 1.16+ (for interacting with provisioned clusters)

Configure the provider

Create a providers.tf file:

terraform {
  required_providers {
    spectrocloud = {
      source  = "spectrocloud/spectrocloud"
      version = ">= 0.1"
    }
  }
}

provider "spectrocloud" {
  host    = var.sc_host
  api_key = var.sc_api_key
}

Populate sc_host and sc_api_key (an API key) via a terraform.tfvars file, or use environment variables instead:

export SPECTROCLOUD_HOST=api.spectrocloud.com
export SPECTROCLOUD_APIKEY=5b7aad.........

Then:

terraform init && terraform apply
