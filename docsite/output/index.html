Terraform Provider for Spectro Cloud

The Spectro Cloud Terraform provider lets you manage Palette and Palette VerteX — SaaS or on-prem — as infrastructure as code: cloud accounts, cluster profiles, clusters, and more.

This site collects working, copy-paste-runnable examples pulled directly from the provider repository's examples/ folder, plus the full resource and data source reference.
