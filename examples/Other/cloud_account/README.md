# cloud_account

There is no `spectrocloud_cloud_account` resource or data source in this provider - only the
per-cloud `spectrocloud_cloudaccount_<aws|azure|gcp|...>` types, under `Infrastructure/Cloud
Accounts/`. A stale, orphaned duplicate example under this name (byte-identical to the AWS cloud
account example) was found during the navigation reorg and has since been removed. This folder is
kept only as a marker so a future reader searching for `cloud_account` finds this note instead of
nothing.
