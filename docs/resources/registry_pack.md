# spectrocloud_registry_pack (Resource)

  Resource for managing Pack registries in Spectro Cloud. Pack registries host Spectro Cloud packs that Palette synchronizes and makes available to cluster profiles. This is a tenant-level resource.

Pack registries appear in Palette under **Tenant Settings > Registries > Pack Registries**. Use `spectrocloud_registry_oci` for OCI registries and `spectrocloud_registry_helm` for Helm registries.

## Validation and synchronization

Before creating the registry, and whenever `endpoint` or `credentials` change, the provider asks Palette to validate the endpoint and credentials, the same check the Palette UI runs when you save a Pack registry. If Palette cannot reach the registry or the credentials are rejected, the apply fails with Palette's reason and nothing is created or changed.

After the registry is created, Palette synchronizes its packs so they can be used in cluster profiles. Set `wait_for_sync = true` to make Terraform wait for that synchronization. If it fails, the apply fails with the reason Palette reports; if it does not finish within the create or update timeout, Terraform returns a warning instead.

## Example Usage

```terraform
# Pack registry with basic authentication.
resource "spectrocloud_registry_pack" "pack_registry" {
  name     = "my-pack-registry"
  endpoint = "https://registry.example.com:5000"

  credentials {
    credential_type = "basic"
    username        = var.pack_registry_username
    password        = var.pack_registry_password

    # Optional: TLS configuration. Omit the block to send no TLS configuration.
    # Certificates are PEM content, not paths - use file() to read them from disk.
    # tls_config {
    #   ca                   = file("${path.module}/ca.pem")
    #   insecure_skip_verify = false
    # }
  }

  # Optional: wait until Palette has synchronized the registry's packs.
  wait_for_sync = true
}

variable "pack_registry_username" {
  type = string
}

variable "pack_registry_password" {
  type      = string
  sensitive = true
}
```

## Import

Pack registries can be imported using the registry UID or name. This is a tenant-level resource.

```bash
terraform import spectrocloud_registry_pack.example <registry_uid_or_name>
```

You can also use an `import` block:

```terraform
import {
  to = spectrocloud_registry_pack.example
  id = "my-pack-registry"
}
```

The import reads the name, endpoint, username and TLS configuration from Palette. Palette does not return the password, so set `password` in the configuration after importing; until then, `terraform plan` shows it as a change.

**Note**: Since this is a tenant-level resource, make sure the provider is configured with credentials that have tenant-level access.
