# spectrocloud_hardened_images (Data Source)

  Provides the hardened image rollout status for a tenant. Palette propagates the Spectro Cloud registry image pull secret to managed workload clusters so they can pull hardened images, and this data source reports how far that rollout has progressed.

The report always covers the tenant the provider is authenticated against. Both arguments are optional server-side filters; omit them to retrieve every cluster in the tenant.

## Example Usage

```hcl
# Retrieve the hardened image rollout status for the whole tenant
data "spectrocloud_hardened_images" "current" {}

# Narrow the report to a single project
data "spectrocloud_hardened_images" "production" {
  project_uid = var.production_project_uid
}

output "hardened_image_rollout_state" {
  value = data.spectrocloud_hardened_images.current.state
}

output "hardened_image_failures" {
  value = data.spectrocloud_hardened_images.current.failed_clusters_count
}
```

## Schema

### Optional

- `cluster_name` (String) Restrict the report to clusters whose name matches this value.
- `project_uid` (String) Restrict the report to clusters that belong to the project with this unique identifier.

### Read-Only

- `clusters` (List of Object) One entry per cluster the filters matched, reporting how far the hardened image pull secret rollout has progressed on that cluster. Clusters that are currently opted out are listed too. (see [below for nested schema](#nestedatt--clusters))
- `excluded_cluster_uids` (Set of String) Unique identifiers of the clusters that are currently opted out of hardened image pull secret propagation.
- `failed_clusters_count` (Number) Number of enrolled clusters that Palette could not deliver the image pull secret to. Inspect the `clusters` attribute for the per-cluster failure reason.
- `id` (String) The ID of this resource.
- `state` (String) Aggregated rollout progress for the tenant. Palette reports `Completed` once every enrolled cluster holds the secret, `InProgress` while the rollout is running, and `Failed` when at least one cluster could not be updated.
