# spectrocloud_rate_config (Data Source)

  Provides the tenant-level cloud rate config, the unit prices Palette uses to estimate cluster cloud cost and usage cost.

The rate config is a tenant-level singleton, so this data source takes no arguments and always returns the rate config of the tenant the provider is authenticated against.

## Example Usage

```hcl
# Retrieve the tenant cloud rate config
data "spectrocloud_rate_config" "current" {}

# Output the vSphere CPU rate Palette uses for cost estimates
output "vsphere_cpu_unit_price_per_hour" {
  value = data.spectrocloud_rate_config.current.vsphere[0].cpu_unit_price_per_hour
}
```
