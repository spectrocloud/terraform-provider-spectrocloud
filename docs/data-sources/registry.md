# spectrocloud_registry (Data Source)

  Data source for looking up an OCI, Helm, or Spectro registry by name.

## Example Usage

```terraform
# Looks up an OCI, Helm, or Spectro (pack) registry by name.
#
# Lookup keys:
#   name - Required.
#   type - Optional, default "". Allowed: "", "oci", "helm", "spectro". If omitted, the
#          registry type is inferred by trying spectro/pack lookup first.
data "spectrocloud_registry" "my_registry" {
  name = "my-registry"
  # type = "helm"
}

# Computed outputs:
#   registry_id
#   registry_sync_status - Helm registries only - null/empty for oci and spectro registries.
output "registry_id" {
  value = data.spectrocloud_registry.my_registry.id
}

output "registry_sync_status" {
  value = data.spectrocloud_registry.my_registry.sync_status
}
```

## Schema

### Required

- `name` (String) Name of the registry to look up.

### Optional

- `type` (String) The type of the registry. Possible values are 'oci', 'helm', or 'spectro'. If not provided, the registry type will be inferred from the registry name.

### Read-Only

- `id` (String) The ID of this resource.
- `sync_status` (String) The synchronization status of the registry. Possible values: 'Completed', 'InProgress', 'Failed', 'Error', etc. Available for Helm registries only.
